# 📊 Aplikasi Pembelajaran Matematika: Penyebaran Data Statistika

Aplikasi web interaktif berbasis React & Vite yang dirancang khusus untuk siswa Kelas VIII SMP dalam mempelajari materi **Penyebaran Data Statistika** (Jangkauan, Kuartil, Simpangan Rata-rata, dan Simpangan Baku). 

Aplikasi ini dikembangkan berdasarkan prinsip **Cognitive Load Theory (CLT)** untuk mengurangi beban kognitif siswa dalam memahami prosedur komputasi dan notasi matematis.

## ✨ Fitur Utama
1. **Modul Materi Interaktif (One Concept per Screen):**
   * Penjelasan ringkas Jangkauan, Simpangan Kuartil, Simpangan Rata-rata, dan Simpangan Baku.
   * Reduksi *Extraneous Load* melalui visualisasi yang bersih dan bebas teks panjang.
2. **Kalkulator Step-by-Step:**
   * Membantu siswa memahami alur perhitungan bertahap (*Mean* → *Deviasi* → *Kuadrat Deviasi* → *Simpangan Baku*).
   * Mencegah kesalahan berantai (*error propagation*) dalam perhitungan manual.
3. **Latihan Soal & Evaluasi (5 Soal Mathematical Literacy):**
   * Berbasis 4 indikator literacy (Reasoning, Formulating, Employing, Interpreting).
   * Umpan balik langsung (*instant feedback*) beserta pembahasan bertahap.
